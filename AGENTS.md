# AGENTS.md

## Repository Guidance & Operational Rules

1. **Medical Disclaimer**:
   - This project is strictly an educational ECG screening demonstration and research effort. It is **not** a certified medical device and must never be presented as one.

2. **Strict Accuracy & Empirical Reporting**:
   - Never invent or fabricate accuracy, precision, recall, or performance metrics.
   - Only report results, evaluation metrics, and statistics directly derived from scripts that have been executed on empirical data.

3. **Deletion Policy**:
   - Ask for explicit user approval before deleting any files, scripts, or legacy assets.

4. **Data & Large File Management**:
   - Never commit raw datasets, large CSV files (`ptbxl_database.csv`, `scp_statements.csv`, `ecg_dataset.csv`), or binary model files (`.h5`, `.pkl`) directly into the Git repository without explicit permission.

5. **Factual Documentation**:
   - The `README.md` and documentation must accurately describe only the code, architecture, endpoints, and features that actually exist in the codebase.
